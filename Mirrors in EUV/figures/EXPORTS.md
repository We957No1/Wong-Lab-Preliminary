# Figure exports

Running all non-interactive cells in `five_mirror_EUV_projection_simulation.ipynb`
populates this directory with matching 300 dpi PNG and vector PDF versions of:

1. Mirror reflectivity and cumulative intensity
2. Pupil apodization
3. Optiland ray diagram
4. Final wafer ray shape
5. M3 geometry sensitivity

The interactive coating-widget plot is intentionally not exported because its
state is temporary until the chosen values are copied into the main configuration.
